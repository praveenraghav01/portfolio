A technical-blog theme for a self-hosted WordPress.org install, built to match
the git/terminal design language of praveenraghav.com. Posts read as a
`git log`, a single post as a commit, tags as chips, search as `grep`,
comments as a terminal thread.

See INSTALL.md in this folder for setup steps.
